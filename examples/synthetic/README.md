# Legacy v1 synthetic routing example

`records.csv` is invented test data. It contains no external or user-provided records.

이 예제는 legacy v1의 capture → frame → deterministic route → approval binding을 확인하기
위한 입력이다. CSV를 변환하거나 모델로 처리하는 데모가 아니다. `frame.example.json`은
schema-valid illustration이며 all-zero digest는 placeholder라 runtime binding으로 사용할 수
없다. v2 의사결정 데모는 `examples/decision-triage/`를 사용한다.
